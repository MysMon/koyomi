# バージョニング

`@koyomi-cal/react` の semver（セマンティックバージョニング）運用ポリシーです。

## 基本方針

バージョン番号は `MAJOR.MINOR.PATCH` の形式で、[セマンティックバージョニング](https://semver.org/lang/ja/) に従います。

- **PATCH** — 挙動を変えないバグ修正・内部実装の変更（配布物のバンドルサイズ削減、依存の脆弱性対応など）
- **MINOR** — 互換性を保った機能追加（新しいビュー・オプション・コンポーネント・公開 API の追加）
- **MAJOR** — 破壊的変更（既存の呼び出しコードが型エラーになる、または実行時の挙動が変わる変更）

対象は `@koyomi-cal/react` が公開する API（`docs/api.md` に列挙されるすべてのエクスポート、
`data-koyomi-*` 属性・デフォルトテーマの CSS 変数名・クラス構造）です。`src/` 内部の実装詳細
（非公開の関数・ファイル分割）はこの対象に含まれません。

## 0.x 系での運用

`0.x` の間は semver の慣例どおり、`MINOR` バージョンでも破壊的変更を許容します。ただし
Koyomi では次の運用で変更の追跡性を保ちます。

- 破壊的変更を含むコミットは `feat!:` / `fix!:` のように `!` を付けた commit type で示します
- `CHANGELOG.md` の該当バージョンに **[破壊的]** タグ付きで変更内容を明記します
- 既存の呼び出しコードへの影響（型の変化・実行時の挙動変化・移行方法）を `CHANGELOG.md` の
  該当項目に書きます

## 破壊的変更の扱い

破壊的変更を伴う変更を行う場合、次を満たします。

1. **理由が明確であること** — 設計上の欠陥の是正、より正確な仕様への修正など、変更しない
   ことのコストが移行コストを上回ると判断できること
2. **`CHANGELOG.md` に記録すること** — 何が変わり、既存コードにどう影響するかを具体的に書く
   （型シグネチャの変化、実行時の挙動変化、削除された API の代替手段）
3. **利用者向けドキュメントを同時に更新すること** — `docs/*.md` と公開 TSDoc は常に「現在の
   仕様」のみを記述するため、変更後の docs には経緯を書かず、`CHANGELOG.md` にのみ経緯を残す
4. **可能な場合は非推奨期間を設けること** — 既存 API を残したまま新 API を追加し、次の
   `MINOR`/`MAJOR` で既存 API を削除する猶予を設けられる場合はそうする。ただし 0.x の間は
   利用実績が限定的なため、猶予を設けずに直接置き換えることも許容する

## 1.0 への安定化基準

次の基準をすべて満たした時点で `1.0.0` をリリースします。1.0 以降は上記の破壊的変更の
猶予（0.x での即時置き換えの許容）を廃止し、通常の semver（破壊的変更は必ず `MAJOR`）に
移行します。

- **API 面の安定**: 月・週・日・リスト・年・複数月・リソース・タイムラインの全ビュー、
  ドラッグ作成・移動・リサイズ、繰り返し予定の編集スコープ、マルチタイムゾーン、RRULE
  対応という中核機能について、公開 API のシグネチャ変更が実運用のフィードバックにより
  必要とされなくなったこと
- **互換性維持ポリシーの明文化**: 本ドキュメントが定める破壊的変更の運用ルールに従った
  リリースが継続していること
- **テスト・型の網羅性**: `pnpm check`（Lint・型チェック・単体テスト）と Playwright に
  よる実ブラウザ E2E（Chromium/Firefox/WebKit）が CI で継続的に通過していること
- **ドキュメントの完成度**: `docs/api.md` の見出しと公開 export が 1:1 対応しており、
  全公開 API に日本語 TSDoc が付与されていること

## 対応 React バージョンの扱い

`peerDependencies` の `react`/`react-dom` の対応範囲変更（サポート追加・打ち切り）は
`MINOR` または `MAJOR` のどちらでも起こり得ます。既存のサポート範囲を**狭める**変更
（例: 対応 React メジャーバージョンの引き上げ）は破壊的変更として扱い、`MAJOR`
（1.0 以降）または `!` 付きの commit type（0.x の間）で示します。
