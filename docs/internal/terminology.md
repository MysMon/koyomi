# 用語ガイドライン（内部）

Koyomi の日本語（コメント・TSDoc・ドキュメント・テスト名・エラーメッセージ）で使う訳語の方針。
英語の技術用語を字面どおり直訳した「直訳調」の語や、意味がずれる語を避け、一貫した自然な日本語を保つ。

この方針は `scripts/check-terms.mjs`（`pnpm terms` / `pnpm check` から実行）で機械的に強制する。
禁止語を書くと `pnpm check` が失敗する。正当な例外がある行には `koyomi-terms-ok` コメントを付けて除外できる。

## 禁止語 → 推奨語

| 使わない（直訳・不正確） | 使う | 対応する英語 / 補足 |
| --- | --- | --- |
| 壁時計 / 壁時計時刻 | **現地時刻 / 現地日時** | wall clock (time)。対比語は「絶対時刻」。識別子 `WallClock*` は英語のまま |
| 発生（名詞） | **オカレンス** | EventOccurrence（繰り返しの1回分）。※下記の動詞例外に注意 |
| 前方解決 / 前方に解決 | **繰り上げ（て解決）** | DST で存在しない時刻を直後の実在時刻へ送る処理 |
| 仮想終了分 / 仮想区間 / 仮想長 | **実効終了分 / 実効区間 / 実効長** | `effectiveEnd`。effective は「実効」（「仮想」は誤訳） |
| 射影 / 射影する | **変換 / 変換する** | project。数学の射影ではない |
| 孤児（オーバーライド） | **参照先のない（オーバーライド）** | orphan |
| 埋め草 | **前後月の日付** | 月グリッドの前後月のはみ出し日（leading/trailing days） |
| 日初 | **日の開始 / その日の 0:00** | start of day |
| 名目分数 | **1 日の分（1440 分）等**（「分数」を避ける） | nominal minutes。「分数」は fraction と紛らわしい |
| 窓 | **探索範囲 / 時間枠** | window（時間範囲の意味のとき） |
| エコーループ | **循環（呼び出し）防止** | echo loop |
| インスタント | **時点** | instant（「即席」と紛らわしい） |
| コンテンツ注入 | **コンテンツの差し込み / 挿入** | content injection（DI を連想させる） |
| 解釈タイムゾーン | **解釈に用いるタイムゾーン** | interpretation timezone |
| 対称のフィールド | **対になるフィールド** | symmetric field |
| 分区間 | **その日に該当する区間** | — |
| 契約 / DOM 契約 / コールバック契約 | **仕様 / DOM 仕様 / コールバックの仕様** | contract（法的な契約を連想させる） |

## 動詞「発生する」は許容

「発生」は名詞（EventOccurrence）としては使わないが、**動詞**（＝起こる・生じる）としては自然な日本語なのでそのまま使う。

- ✅ 動詞: `9:00 に発生する` / `DST が発生する` / `pointermove が発生した` / `通知を発生させない`
- ❌ 名詞: `クリックされた発生` → `クリックされたオカレンス`、`各発生` → `各オカレンス`

チェックは `発生` の直後が「す・し・さ・せ」で始まる活用（発生する/し/さ/せ）を動詞とみなして許容し、それ以外（名詞用法）を禁止する。稀に動詞由来の名詞（例:「例外発生時」）で誤検知した場合は、その行に `koyomi-terms-ok` を付ける。

## 補足

- `resolve` の訳: 抽象的な入力から具体値を求める処理は **算出する / 変換する**。JS の Promise 文脈など一般的な「解決」は許容（機械チェック対象外）。
- 定着したカタカナ借用語（オフセット・フォールバック・クランプ・レーン・スナップ・ドラッグ 等）はそのまま使ってよい。
- **ミニ月グリッド**: 年ビュー（`year`）が 1 年分並べる、月ビューと同じ構造の小さな月グリッド 1 つ分を指す語。禁止語ではなく、年ビュー関連のコメント・TSDoc・docs での呼称を揃えるための推奨語（単に「月グリッド」と書くと月ビュー本体のグリッドと紛らわしいため使い分ける）。
- 新たに直訳調の語を見つけた場合は、推奨語を決めたうえで本表と `scripts/check-terms.mjs` の両方に追記する。
